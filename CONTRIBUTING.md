# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate your interest in improving this project. You can contribute by reporting bugs, suggesting new features, improving documentation, or submitting code changes.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Submit a pull request describing your contribution.

Thank you for contributing to the Simple Interest Calculator project!
